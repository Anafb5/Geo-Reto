# GeoReto

Juego de 20 preguntas en 4 rondas, basado en el PDF «La vuelta al mundo · Concurso de cumpleaños».

Incluye 15 preguntas de opción múltiple y 5 preguntas de banderas con respuesta libre. Cada acierto vale 10 puntos. Dispone de corrección automática, revisión de resultados y récord personal guardado en el navegador.

## Publicación

Para activar GitHub Pages: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

Dirección una vez activado: https://anafb5.github.io/Geo-Reto/
